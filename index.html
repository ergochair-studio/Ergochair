ErgoChair Studio · GitHub Pages Guide MONITOR 2 PWA
1. Hosting on GitHub Pages: Upload the ergochair-web folder files (index.html, manifest.json, sw.js, icon.svg, .nojekyll) to a GitHub repository and enable Settings → Pages → Deploy from branch (main / root).
2. Phone Installation & Offline Mode: Open your https://<user>.github.io/<repo>/ link in Chrome on Android and tap Install App (or Chrome Menu → Add to Home screen). It caches offline automatically via Service Worker and unlocks Web Bluetooth.
3. Per-Profile Saved History: Each Netflix-style profile saves its own daily sitting time, good/poor posture ratio, alerts, breaks, and multi-day trend locally on your phone. Use Settings → Export Backup (.json) anytime to back up or transfer data.
4. 2-Split Simultaneous Monitor & Alerts: Monitor any 2 panels together on the main screen (default: Detected Posture live animation on top, Posture Score below), or switch directly to dedicated windows from the bottom dock.
